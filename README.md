## 📌 О проекте
**SignBridge-Edge** — автономная система распознавания **казахско-русского жестового языка (КРЖЯ)** и перевода в текст и речь. Работает полностью на устройстве (смартфон, Raspberry Pi) без интернета, поэтому видео никогда не покидает устройство.

Обратное направление (речь → текст на экране; в перспективе — текст → жест через аватар) реализуется отдельным модулем и описано в roadmap как самостоятельный этап.

## 🎯 Решаемая проблема
Глухие и слабослышащие люди сталкиваются с барьерами при получении базовых услуг: в поликлинике, ЦОНе, банке, учебном заведении. Сурдопереводчиков не хватает, особенно за пределами крупных городов. Проект даёт инструмент для коротких бытовых диалогов там, где переводчика нет.

> **Проект не заменяет профессионального сурдопереводчика**, особенно в медицинских, юридических и других ситуациях, где цена ошибки высока.

## 🤝 Принцип «Ничего о нас без нас»
Проект разрабатывается **вместе с сообществом глухих**:
* носители КРЖЯ участвуют в сборе данных, разметке и тестировании;
* приоритет сценариев определяют сами пользователи;
* участники получают вознаграждение и указываются как соавторы датасета;
* партнёры: общественные объединения глухих, специальные школы-интернаты, сурдопереводчики.

## 🧩 Что распознаётся
| Уровень | Описание | Этап |
|---|---|---|
| Изолированные жесты | Отдельные слова из словаря (≈ 200–500 жестов бытовой тематики) | ✅ MVP |
| Дактиль (пальцевая азбука) | Имена, названия | ⚙️ Этап 2 |
| Непрерывная речь | Предложения из нескольких жестов | 🔬 Исследование |
| Немануальные компоненты | Мимика, движения головы и корпуса (несут грамматику: вопрос, отрицание) | ⚙️ Учитываются с этапа 2 |

Жестовый язык — самостоятельный язык со своей грамматикой, а не «слова руками». Поэтому последовательность распознанных жестов (глоссов) переводится в текст отдельной языковой моделью, а не простой склейкой.

## 🛠 Стек технологий
* **Трекинг:** MediaPipe Tasks — **Holistic Landmarker** (руки, поза, лицо)
* **Модели:** PyTorch для обучения (Transformer / GRU по последовательностям ключевых точек)
* **Инференс на устройстве:** **LiteRT** (бывший TensorFlow Lite) или **ExecuTorch** (замена PyTorch Mobile)
* **Глоссы → текст:** компактная локальная языковая модель с поддержкой казахского и русского языков
* **Речь:** локальные модели TTS (озвучивание) и ASR (распознавание речи собеседника) для KZ/RU
* **Интерфейс:** OpenCV (прототип) → Flutter (мобильное приложение)

## ⚙️ Архитектура
```
Камера ─▶ Holistic Landmarker ─▶ Нормализация точек ─▶ Модель жестов ─▶ Глоссы
                                                                          │
                                                                          ▼
                    Экран / TTS (KZ, RU) ◀── Текст ◀── Языковая модель (глоссы → текст)

Собеседник: Речь ─▶ ASR ─▶ Текст крупным шрифтом на экране
```
1. **Захват видео** в реальном времени.
2. **Ключевые точки.** На модель передаются только координаты, а не изображение, что снижает нагрузку и повышает приватность.
3. **Нормализация.** Приведение к единому масштабу и положению, независимо от расстояния до камеры.
4. **Классификация** последовательности точек.
5. **Языковой модуль:** глоссы → грамматически правильный текст.
6. **Обратная связь:** речь собеседника распознаётся и выводится текстом.

## 📚 Данные
| Источник | Описание |
|---|---|
| **K-RSL** (Назарбаев Университет) | Датасет казахско-русского жестового языка — основа для старта |
| Собственный сбор | Записи носителей КРЖЯ по бытовым сценариям (поликлиника, ЦОН, магазин, транспорт) с информированным согласием |
| Аугментация | Зеркалирование (для левшей), шум, вариации скорости |

**Разнообразие выборки.** Возраст, пол, левши и правши, разные тона кожи, освещение, фон, региональные варианты жестов.

## ⚖️ Справедливость и проверка смещений
Качество трекинга ключевых точек может зависеть от тона кожи, освещения и характеристик камеры. Проект **не заявляет отсутствие смещений**, а измеряет их:
* метрики точности отдельно по группам (тон кожи, возраст, освещение, тип устройства);
* публикация результатов в Model Card;
* целевой разрыв точности между группами — не более 5 п.п.

## 📏 Метрики
| Метрика | Что измеряет |
|---|---|
| Top-1 / Top-5 accuracy | Точность распознавания изолированных жестов |
| WER по глоссам | Ошибки в непрерывной речи (этап исследования) |
| Задержка (мс) | Время от жеста до текста на целевом устройстве |
| Разрыв точности между группами | Справедливость |
| Оценка пользователей | Тестирование с носителями КРЖЯ |

## 🔐 Приватность
* Обработка только на устройстве; видео не сохраняется и не передаётся.
* Для сбора датасета — отдельное информированное согласие, право отозвать записи.

## 🚧 Ограничения
* Словарь MVP ограничен бытовыми темами.
* Непрерывная речь и перевод «текст → жест» (аватар) — исследовательские задачи следующих этапов.
* Качество снижается при плохом освещении и частичном перекрытии рук.

## 🗺 Roadmap
**Этап 1. MVP — изолированные жесты**
- [ ] Интеграция Holistic Landmarker и нормализация точек

- [ ] Учёт мимики и дактиля
- [ ] Отчёт о проверке смещений

**Этап 3. Диалог**

**Этап 4. Исследование**
- [ ] Непрерывное распознавание
- [ ] Перевод текст → жест через аватар
