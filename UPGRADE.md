# Доработка и доказательства готовности

Дата: 2026-10-09.

## Реализовано

Синтетические и неизвестные модели больше не создают перевод и речь. Реальная модель требует явных metadata real_data_verified=true и evaluation.signer_disjoint=true; это декларация автора, которую нужно подтвердить отчётом. Добавлены отказ при низкой уверенности/малой разнице классов, остановка камеры, освобождение треков при уходе со страницы, обработка ошибок и защита от одновременных infer вызовов. Исправлена обработка плоских landmarks MediaPipe.

## Запуск и проверка

```bash
python -m pytest -q
node --test tests/policy.test.mjs
python -m http.server 8080 --directory web
```

Регрессионные тесты: `python -m pytest -q`. Локальная среда проверки: Windows, Python 3.12. CI проверяет отдельную чистую среду.

## Что требуется для оценки 10/10

Нужен согласованный корпус реального КРЖЯ и полноценные тесты на отдельных людях, неизвестных жестах, освещении и устройствах. Текущие веса остаются синтетическими. Порог .7 и margin .15 — начальные эвристики, не калиброванные вероятности. Сравнить распознавание и текст с носителями языка. Браузер загружает зависимости из CDN; гарантированной офлайн-доступности пока нет.

Инженерные тесты подтверждают поведение кода; они не измеряют клиническую, гидрологическую или коммерческую точность. Метрики на синтетике нельзя переносить на реальные данные. Оценка 10/10 сейчас не заявляется.
