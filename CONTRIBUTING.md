# Участие в проекте

Принцип проекта — **«Ничего о нас без нас»**. Нужны носители КРЖЯ, сурдопереводчики, разработчики мобильных приложений и CV.

## Запись данных
* Только с информированного согласия (`data/consent_registry.template.csv` → `data/consent_registry.csv`), с правом отозвать записи (`scripts/record_samples.py --revoke <id>`).
* Сохраняются только координаты ключевых точек, не видео.
* Участники получают вознаграждение и указываются соавторами датасета (если они этого хотят).
* Записи людей не попадают в публичный репозиторий без отдельного согласия.

## Словарь
* Состав и приоритет жестов определяют носители языка (`data/vocab/glosses.json`).
* Описания конфигураций дактиля (`data/vocab/dactyl_kk.json`) заполняются вместе с сурдопереводчиками.

## Код
* Issue → pull request; перед PR: `pytest -q`.
* Любое изменение модели сопровождается отчётом о точности по группам (`docs/MODEL_CARD.md`).
